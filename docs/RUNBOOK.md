### Outbreak Alert Escalation Protocol

```
+-------------------------------------------------------------------------------+
|  ALERT LEVEL 1: ADVISORY (Case Count >= 2, STPSS p < 0.10, or Chlorine Dip)  |
|  - Action: Automated Warden push notification.                               |
|  - Check: Floor RO sump inline chlorine level.                                |
|  - Notification: "Drink boiled water; stay hydrated."                         |
+-------------------------------------------------------------------------------+
                                      |
                                      v
+-------------------------------------------------------------------------------+
|  ALERT LEVEL 2: TARGETED ALERT (Case Count >= 5, STPSS p < 0.05, Bayes > 70%) |
|  - Action: Immediate CMO Notification & Emergency Warden Taskforce.          |
|  - Physical Isolation: Lock Floor RO Intake Valve. Bypass to backup supply.   |
|  - Kitchen Action: Suspend identified suspect dish (e.g. Palak Paneer).       |
|  - Hydration Deployment: Place ORS sachets at hostel floor reception.        |
+-------------------------------------------------------------------------------+
                                      |
                                      v
+-------------------------------------------------------------------------------+
|  ALERT LEVEL 3: INSTITUTIONAL EMERGENCY (Case Count >= 12 or Water Contam)    |
|  - Action: Executive Dean & District Epidemiological Notification.            |
|  - Medical Taskforce: Mobile IV fluid hydration unit deployed to block.       |
|  - Emergency De-anonymization: Dual CMO + DPO authorization unlock.           |
+-------------------------------------------------------------------------------+
```
